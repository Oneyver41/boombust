Privacy Policy — Boom & Bust Pipeline

Last updated: October 5, 2026

Boom & Bust Pipeline ("the app") is a private tool used exclusively by the owner of the YouTube channel Boom & Bust Files to manage that channel. It is not offered to the public.

Data the app accesses

  • YouTube: the owner's own channel, to upload videos, set thumbnails and subtitles, edit video metadata, and read the channel's statistics and analytics reports.
  • Google Drive: only files and folders created by the app (scope drive.file), used to store videos for review.

How the data is used

Data is used only to produce, upload and improve videos for the owner's channel. It is never sold, shared with third parties, or used for advertising.

Storage

OAuth tokens and downloaded reports are stored only on the owner's personal computer. No data is sent to any server operated by the app.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored tokens can be deleted on request.
